# Introdução

Este documento descreve os principais casos de uso da versão 1.0 do sistema MOTIX.

Os casos de uso representam as interações entre os usuários e o sistema.

---

# Ator Principal

Administrador da Concessionária

O administrador é responsável por gerenciar todas as informações da concessionária.

## UC-002 – Consultar Cliente

## UC-003 – Atualizar Cliente
