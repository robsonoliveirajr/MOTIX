# 1. Origem do Projeto

O MOTIX nasceu da união entre duas paixões: veículos e tecnologia.

Desde criança sempre fui apaixonado por carros e motocicletas. Como muitas crianças, sonhava em ter uma garagem repleta de veículos.

Com o tempo, esse sonho amadureceu. Ao conhecer a programação e a Engenharia de Software, percebi que sonhos de infância também podem se transformar em projetos reais.

O MOTIX representa exatamente essa transformação.

Mais do que um sistema para gerenciamento de concessionárias, ele será um ambiente para aplicar conhecimentos em Programação Orientada a Objetos, Engenharia de Software, Banco de Dados, Arquitetura de Software e boas práticas de desenvolvimento.

Além de servir como projeto de estudo, o desenvolvimento será totalmente documentado, registrando decisões de arquitetura, desafios encontrados e aprendizados durante toda a construção do software.

---

# 2. Problema

Concessionárias precisam controlar diversas informações diariamente, como clientes, funcionários e veículos disponíveis para venda.

Sem um sistema organizado, esses dados podem ficar descentralizados, dificultando consultas, atualizações e o gerenciamento do negócio.

---

# 3. Solução

O MOTIX será um sistema desenvolvido para centralizar o gerenciamento de uma concessionária.

Inicialmente o sistema permitirá cadastrar, consultar e gerenciar clientes, funcionários e veículos.

Nas próximas versões serão adicionadas funcionalidades como gerenciamento da oficina, ordens de serviço, histórico de manutenção, persistência em banco de dados, API e outras melhorias.

# 5. Objetivos

## Objetivo Geral

Desenvolver um software completo utilizando boas práticas de Engenharia de Software para consolidar conhecimentos em desenvolvimento Backend.

## Objetivos Específicos

- Aplicar Programação Orientada a Objetos.
- Aplicar princípios SOLID.
- Desenvolver uma arquitetura organizada.

---

# 6. Escopo da Versão 1.0

A primeira versão do MOTIX será responsável apenas pelo gerenciamento básico da concessionária.

Ela permitirá:

- Cadastro de clientes.
- Cadastro de vendedores.
- Cadastro de mecânicos.
- Cadastro de carros.
- Cadastro de motos.
- Controle do estoque de veículos.
- Consultas aos dados cadastrados.

Não fazem parte da versão 1.0:

- Oficina.
- Ordem de Serviço.
- Banco de Dados.
- API.
- Interface Gráfica.
- Relatórios.
- Sistema de Login.
