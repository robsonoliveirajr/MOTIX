# 🚗 MOTIX

> ⚠️ **Projeto em desenvolvimento**
>
> O MOTIX está sendo desenvolvido seguindo práticas de Engenharia de Software.
> O objetivo é construir um sistema completo de gerenciamento para concessionárias documentando todas as etapas do desenvolvimento, desde o levantamento de requisitos até a implementação.

---

## 📌 Objetivo

Desenvolver um sistema de gerenciamento para concessionárias utilizando Python, Programação Orientada a Objetos, SOLID e boas práticas de Engenharia de Software.

---

## 🚀 Tecnologias

- Python
- Git
- GitHub
- Programação Orientada a Objetos
- Engenharia de Software
